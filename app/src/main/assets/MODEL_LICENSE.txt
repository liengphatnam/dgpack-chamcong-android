Model: mobilefacenet.tflite
Nguồn tải: https://github.com/MCarlomagno/FaceRecognitionAuth/blob/master/assets/mobilefacenet.tflite
Repo gốc license: BSD 3-Clause (Copyright (c) 2020, Marcos Carlomagno)

Đặc tả model (đã xác minh từ header flatbuffer + code tham chiếu lib/services/ml_service.dart
của repo trên):
  - Input:  float32, shape [1, 112, 112, 3], chuẩn hoá mỗi kênh RGB theo công thức
            (pixel - 128) / 128 (giá trị nằm trong khoảng [-1, 1]).
  - Output: float32, shape [1, 192] — vector embedding 192 chiều.

Model gốc là kiến trúc MobileFaceNet (Chen et al., huấn luyện với InsightFace loss),
được nhiều repo mã nguồn mở khác cũng dùng chung file .tflite tương tự — đây là model
phổ biến trong cộng đồng, không phải hàng độc quyền của riêng repo trên.

license rất thấp. Nếu sau này cần phân phối rộng hơn hoặc dùng cho mục đích thương mại,
